# microWakeWord models

Each local wake word or command model is stored as a pair:

```text
models/
  skadi.json
  skadi.tflite
```

The `.tflite` file is the neural network itself. The `.json` file is the
manifest consumed by ESPHome and describes the phrase, model file, version,
language, and inference parameters.

Example manifest shape:

```json
{
  "type": "micro",
  "wake_word": "Скади",
  "author": "Your name",
  "website": "https://example.com",
  "model": "skadi.tflite",
  "trained_languages": ["ru"],
  "version": 2,
  "micro": {
    "probability_cutoff": 0.95,
    "feature_step_size": 10,
    "sliding_window_size": 5,
    "tensor_arena_size": 0,
    "minimum_esphome_version": "2025.1.0"
  }
}
```

Do not guess `tensor_arena_size` or probability settings. Keep the values
generated by the training/export tool or copied from a verified model
manifest. The example is a schema guide, not a ready-to-flash model.
