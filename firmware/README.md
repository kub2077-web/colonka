# Прошивка умной колонки ESP32-S3

В этом каталоге находится основная конфигурация ESPHome для прототипа
умной колонки.

## Окружение проекта

Проект использует ESPHome с фреймворком Arduino, потому что SD-плеер работает
через `ESP32-audioI2S`. PlatformIO устанавливается как зависимость ESPHome;
сама прошивка настраивается в YAML.

Из корня репозитория:

```bash
cp firmware/secrets.example.yaml firmware/secrets.yaml
# Отредактируйте firmware/secrets.yaml и замените все заполнители.

make -C firmware validate
make -C firmware compile
make -C firmware upload
make -C firmware logs
```

Для целей `upload` и `logs` ESP32-S3 должен быть подключён по USB. Если плата
не подключена, цели `validate` и `compile` всё равно можно использовать для
проверки конфигурации и создания файла прошивки.

Пароль OTA, веб-панели и fallback-точки доступа должен содержать не менее
8 символов. На этапе прототипирования все три используют один секрет
`speaker_ota_password`. Перед использованием устройства вне доверенной
тестовой сети применяйте разные пароли.

## Карта аппаратных выводов

Редактируемая карта GPIO находится в верхней части
`esp32-s3-speaker.yaml`.

Текущее назначение:

| Функция | GPIO |
| --- | ---: |
| Сенсорное управление: микрофон | 1 / T1 |
| Сенсорное управление: пауза | 6 / T6 |
| Сенсорное управление: громкость вверх | 4 / T4 |
| Сенсорное управление: громкость вниз | 5 / T5 |
| I2S BCLK | 41 |
| I2S WS/LRCLK | 42 |
| Данные INMP441 | 43 |
| Данные MAX98357 | 44 |
| Данные WS2812 | 21 |
| BQ25895 SDA | 15 |
| BQ25895 SCL | 16 |
| SD CMD | 38 |
| SD CLK | 39 |
| SD DATA0 | 40 |

GPIO43 и GPIO44 являются альтернативными выводами UART0. Они намеренно
используются для передачи данных I2S, поэтому последовательное логирование
отключено в YAML.

## Зарезервированные выводы

- GPIO26-GPIO37: OPI PSRAM на N16R8;
- GPIO38-GPIO40: встроенная SDMMC в однолинейном режиме;
- GPIO19-GPIO20: USB;
- GPIO0, GPIO3, GPIO45, GPIO46: загрузочные и конфигурационные выводы.

Альтернативные функции камеры не резервируются прошивкой, потому что камера
не используется. При необходимости GPIO можно изменить в верхней карте
выводов с учётом физического расположения разъёмов на корпусе.

## Диагностика

Диагностический режим входит в состав этой же прошивки. Его можно открыть
через веб-панель ESPHome или удержанием сенсорных площадок микрофона и паузы
в течение пяти секунд.

В первую версию диагностического режима входят:

- проверка цветов светодиодного кольца;
- перезапуск;
- приватность микрофона;
- сущности сенсорных датчиков;
- сканирование I2C;
- состояние API и веб-панели;
- монтирование SD-карты и операции с файлами через `/file/`.

## Сенсорное управление

Четыре физических сенсорных входа используются без дополнительных GPIO:

- микрофон: переключение режима приватности микрофона;
- короткое касание паузы: пауза или продолжение активного источника радио/SD;
- удержание паузы: переключение между радио и SD-плеером;
- короткое касание увеличения/уменьшения громкости: изменение громкости на 5%;
- удержание увеличения громкости: следующая станция или трек;
- удержание уменьшения громкости: предыдущая станция или трек.

Локальные голосовые команды для радио, памяти, перехода назад, перехода
дальше, остановки, увеличения и уменьшения громкости используют тот же общий
маршрутизатор. Последняя распознанная голосовая команда также публикуется
как диагностическая текстовая сущность.

Сервер файлов SD-карты является внешним компонентом ESPHome, зафиксированным
на версии `v0.2.0`. Он предоставляет локальную загрузку, скачивание и
удаление файлов. MP3-плеер использует ту же смонтированную карту и ограничивает
воспроизведение файлами `.mp3`.

## План хранения данных

- `stations.json` и постоянные настройки хранятся во встроенной flash-памяти;
- MP3-файлы находятся в корне встроенной SD-карты;
- в первой версии поддерживается только MP3;
- история shuffle хранится в течение текущей сессии SD и сбрасывается при
  смене источника;
- громкость намеренно не сохраняется в постоянной памяти и после перезагрузки
  устанавливается на 30%.

Начальные схемы постоянных данных находятся в
`firmware/data/stations.json` и `firmware/data/settings.json`. Они намеренно
отделены от содержимого SD-карты: радиостанции и настройки устройства должны
сохраняться при замене карты.

## Настройка Wi-Fi и доступ

Учётные данные маршрутизатора не вшиваются в прошивку. При первом запуске
или если сохранённая сеть недоступна, колонка открывает резервную точку
доступа:

- SSID: `Умная колонка ESP32-S3 Fallback`;
- пароль: локальное значение `speaker_ota_password` из `secrets.yaml`;
- captive portal: `http://192.168.4.1/`;
- веб-панель: `http://192.168.4.1:8080/`;
- вход в веб-панель: `admin` и тот же пароль, что используется для OTA.

Пароль резервной сети, веб-панели и OTA задаётся в `firmware/secrets.yaml` до
сборки прошивки. Это ограничение стандартных компонентов ESPHome: они не
поддерживают безопасную смену этих трёх паролей через captive portal после
первого запуска. Не удаляйте `secrets.yaml` перед сборкой и не публикуйте его
содержимое.

Captive portal используется для выбора и сохранения фактической Wi-Fi-сети
без повторной прошивки. Когда колонка подключена к обычной сети, веб-панель
доступна по адресу:

```text
http://esp32-s3-smart-speaker.local:8080/
```

Веб-панель работает на порту `8080`, чтобы не конфликтовать с captive portal
на порту `80`. Для обнаружения устройства используется mDNS, поэтому доступ
к таблице DHCP маршрутизатора не требуется. Некоторые гостевые сети запрещают
обмен данными между клиентами или mDNS; в этом случае подключитесь к резервной
точке доступа для повторной настройки.

## Секреты ESPHome

Перед компиляцией скопируйте `secrets.example.yaml` в `secrets.yaml` и
локально замените все значения-заполнители. Файл `secrets.yaml` игнорируется
Git.

## Документы для пользователя

- `ТЕСТОВЫЙ_РЕЖИМ.md` — запуск диагностики кнопками и перечень проверок после
  прошивки;
- `ИНСТРУКЦИЯ_ПО_ЭКСПЛУАТАЦИИ.md` — краткая инструкция для потребителя без
  описания тестового режима.

При глубоком разряде колонка пробуждается по таймеру раз в 60 секунд. Это
нужно, потому что на корпусе нет отдельной кнопки питания или пробуждения.

## Ограничения первой версии

- Home Assistant пока остаётся отдельным источником. Общий аудиопуть
  `media_player` уже присутствует, но автомат воспроизведения предоставляет
  только источники `NONE`, `RADIO` и `SD`. Отдельный источник `HA_MEDIA`
  отложен до определения правил эксклюзивного переключения.
- Громкость действует только во время работы. После перезагрузки колонка
  запускается с громкостью 30% и не записывает изменения громкости в
  Preferences или flash-память ESPHome.
- BQ25895 подключён к общей шине I2C. Пакет настраивает ток заряда 640 мА,
  лимит входного тока 1000 мА и напряжение заряда 4,208 В. Он публикует
  напряжение аккумулятора, системное и входное напряжение, ток заряда и
  входной ток, оценку заряда по напряжению, уровень NTC, состояния зарядки,
  наличия питания, полного заряда и boost-преобразователя, признаки низкого
  и критического заряда, а также текстовые статусы зарядки и ошибок.
